# AtDev Billing — Hybrid plans (FileRadar)

**Status:** proposal only. FileRadar's local scanning and analysis features remain free and usable without an account.

## Hybrid model

FileRadar is a local, read-only storage analyzer. Do not paywall local scanning, duplicate detection, reports, or basic export. Potential paid offerings are limited to future optional conveniences such as managed team report storage, centralized fleet dashboards, or enterprise support, if actually developed.

## Proposed tiers (CLP/month; exploratory)

| Plan | Reference price | Scope |
| --- | ---: | --- |
| Community | $0 | Full local application and local reports |
| Supporter | Voluntary | Optional contribution to development; no essential feature lock |
| Team | $1,990 | Future centralized team reporting, only after implementation |

The Supporter amount should be selected by the supporter; no payment feature is currently enabled. Team pricing is only a placeholder and must be validated against hosting and support costs.

## Privacy requirements

Scanning stays local by default. Never upload filenames, paths, file hashes, or storage reports unless the user explicitly opts in to a clearly described hosted feature. Do not collect file contents for monetization. Billing must not change the read-only safety behavior.

No checkout is active. Real-money features require an adult account owner's review of provider eligibility and legal/tax obligations.
